📘 OpenClaw 配置指南

1. 生成 Token

点击上方「+ 生成 Token」按钮，选择有效期和权限范围，然后复制生成的 Token。

2. 配置 OpenClaw

编辑 OpenClaw 配置文件（通常为 ~/.openclaw/config.json）：

{
  "mcp": {
    "servers": {
      "audio-learning": {
        "command": "python",
        "args": ["-m", "openclaw_learning_server.server"],
        "env": {
          "LEARNING_API_URL": "http://localhost:5000",
          "LEARNING_API_TOKEN": "你的Token"
        }
      }
    }
  }
}

3. 安装 MCP Server

cd mcp-server
pip install -e .

4. 使用示例

配置完成后，在 OpenClaw 中即可通过自然语言交互：

  • "我今天该学什么？" → 获取督促提醒
  • "帮我制定本周学习计划" → 创建学习计划
  • "我最近学得怎么样？" → 获取学习统计
